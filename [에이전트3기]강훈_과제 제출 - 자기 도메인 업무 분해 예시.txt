[도메인 맥락]
나는 게임 개발자 3년 차이고, 매달 유저접속 수 결과를 한장으로 정리하고 싶습니다.

1. 분해: 장르별/접속시간대별/플레이시간별 데이터로 나눔
2. 패턴: 시간대 효과, 장르 종류 효과, 플레이시간 효과 3가지

4. 알고리즘: 데이터 입력 -> 3가지 분리 -> 패턴 추출 -> 인사이트 3개 출력
